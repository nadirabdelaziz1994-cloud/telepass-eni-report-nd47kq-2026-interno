# GRABEGO

Inserire qui il file Grab & Go con nome stabile:

- `GRABEGO.xlsx` consigliato
- `GRABEGO.csv` supportato come alternativa

La build legge automaticamente il file più recente in questa cartella con nome che inizia per `GRABEGO`, rigenera la pagina “Grab & Go” e copia il file pubblicato in `docs/files/GRABEGO/`.

Lo stato “visitato + mese” non viene salvato in questo file: resta nel browser ed è collegato al codice PDV.
